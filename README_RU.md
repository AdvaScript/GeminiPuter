Продвинутая интерактивная прошивка, превращающая **M5Stack Cardputer** и **Cardputer ADV** в карманного ИИ-ассистента на базе **Google Gemini 3.1 Flash-Lite** с поддержкой вызова аппаратных функций устройства, двуязычной русско-английской клавиатурой, веб-консолью управления в реальном времени и динамическими эффектами RGB подсветки.

> [!NOTE]
> **Упоминание оригинала (Форк)**: Данный репозиторий является глубоко модифицированным форком оригинального проекта [GeminiPuter](https://github.com/nishad2m8/GeminiPuter) от разработчика [nishad2m8](https://github.com/nishad2m8). Выражаем признательность автору за базовую идею проекта!

| Возможность | Оригинал (`nishad2m8/GeminiPuter`) | Наш Форк (`AdvaScript/GeminiPuter` v2.0.1) |
| :--- | :--- | :--- |
| **Поддерживаемое железо** | Только базовый M5Cardputer | **M5Stack Cardputer** + **Cardputer ADV** |
| **Совместимость с M5Burner** | Обычный app-бинарник (не стартует с 0x0) | **Полный склеенный образ (Merged Image)** со всеми таблицами и загрузчиком |

| **Модель Gemini** | Зашитая `gemini-1.5-flash` (Устарела / ошибка 404) | **`gemini-3.1-flash-lite`**, `gemini-2.5-flash`, смена прямо из веб-морды |
| **Скорость генерации** | Стандартная задержка "размышлений" (Thinking) | **Режим мгновенного ответа** (`thinkingBudget: 0`) без лишних пауз |
| **Управление железом** | ❌ Отсутствует (только текстовый чат) | ✅ **Function Calling**: Яркость экрана, WS2812 RGB лампа, уровень заряда батареи |
| **RGB LED лампа** | ❌ Не поддерживается | ✅ **11 встроенных эффектов**, анимации из JSON, визуализация в веб-панели |
| **Язык и ввод** | Только английский (QWERTY) | 🇷🇺 **Двуязычный ввод (Русская фонетическая раскладка + Английский)** с HUD уведомлением |
| **Веб-интерфейс** | Простая captive-страница Wi-Fi | 🌐 **Киберпанк Веб-консоль**: Зеркалирование экрана, удаленная клавиатура, телеметрия |
| **Цветовое оформление** | Базовый зеленый цвет | 🎨 **Стильный дизайн**: Электрический синий Gemini (`#38B6FF`), выравнивание запросов вправо |
| **Стабильность и WDT** | Краши по Watchdog при длинных ответах | 🛡️ Раздельные FreeRTOS задачи, мьютексы, защита от сброса сторожевого таймера |
| **Пасхалки** | ❌ Нет | 🤢 Реакция на тряску гироскопа / команда `/shake` |

## ✨ Основные возможности

### 🧠 Gemini 3.1 и Аппаратные функции (Function Calling)
Нейросеть не просто отвечает на вопросы, но и напрямую управляет периферией Cardputer:
- **Яркость подсветки экрана**: `"Сделай экран ярче на 80%"` или `"Поставь яркость на 10%"`.
- **WS2812 RGB лампа**: `"Включи красный свет"`, `"Поставь эффект радуги"`, `"Пульсируй синим"`, `"Выключи лампочку"`.
- **Пользовательские анимации**: ИИ может сам составить покадровый JSON-сценарий анимации светодиода.
- **Опрос датчиков**: `"Какой текущий заряд аккумулятора?"` (возвращает реальные проценты батареи с контроллера питания).

### ⌨️ Русская и Английская клавиатура
- Переключение языка в одно нажатие: сочетание клавиш **`Fn + Backspace`** или **`Fn + Enter`**.
- Всплывающее полупрозрачное HUD-окно на экране: **`[ РУС ]`** / **`[ ENG ]`**.
- Четкий кириллический шрифт (`rubik_14_cy`).

### 🌐 Веб-интерфейс и удаленный ввод
Откройте браузер по адресу `http://<ip-адрес-картпьютера>/` с телефона или ПК:
- **Живая лента диалога**: Синхронное отображение сообщений в виде стильных бабблов (запросы пользователя справа, ответы Gemini слева синим цветом).
- **Удаленная клавиатура**: Печатайте с удобной клавиатуры компьютера с историей команд (стрелки `Вверх`/`Вниз`).
- **Быстрые кнопки (Quick Chips)**: Управление светом, яркостью, батареей и тестом в один клик.
- **Телеметрия устройства**: Индикатор батареи, уровень сигнала Wi-Fi RSSI, аптайм, свободная память (Heap) и интерактивная виртуальная RGB лампа.
- **Настройки**: Смена API-ключа, модели Gemini и Wi-Fi сети прямо из браузера без перепрошивки.

## 🎮 Управление с клавиатуры Cardputer

| Сочетание клавиш | Действие |
| :--- | :--- |
| **`Tab`** | Переключение фокуса между полем ввода и окном диалога |
| **`Fn + ;`** / **`Fn + .`** | Прокрутка истории диалога Вверх / Вниз |
| **`Enter`** | Отправить запрос Gemini |
| **`Fn + Backspace`** или **`Fn + Enter`** | Переключение языка клавиатуры (Русский / Английский) |
| **`Ctrl + L`** | Очистить историю диалога |
| **`/shake`** или **`/puke`** | Запуск пасхалки |

## 📥 Прошивка и установка

### Способ 1: Прошивка через M5Burner или esptool (Рекомендуется)
Скачайте актуальный файл `GeminiPuter.bin` (или `GeminiPuter-v2.0.1-merged-M5Burner.bin`) со страницы [GitHub Releases](https://github.com/AdvaScript/GeminiPuter/releases).

Это **полноценный склеенный образ (Merged Binary)**, готовый для записи с адреса `0x0000`:
- `0x0000`: Загрузчик ESP32-S3 (Bootloader)
- `0x8000`: Таблица разделов (Partition Table)
- `0xe000`: Сектор выбора раздела (Boot App0)
- `0x10000`: Основная прошивка (Firmware)

Прошейте через **esptool.py**:
```bash
esptool.py --chip esp32s3 write_flash 0x0 GeminiPuter.bin
```
Или прошейте/загрузите напрямую в **M5Burner** как файл прошивки!

### Способ 2: Сборка из исходников через PlatformIO
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/AdvaScript/GeminiPuter.git
   cd GeminiPuter/PIO
   ```
2. Скомпилируйте и залейте прошивку:
   ```bash
   pio run -t upload
   ```

## ⚙️ Первичная настройка

1. При первом включении подключитесь к Wi-Fi сети устройства либо настройте подключение по инструкции на экране.
2. Откройте в браузере `http://<ip-адрес-картпьютера>/`.
3. Получите бесплатный API ключ на [Google AI Studio](https://aistudio.google.com/).
4. Введите ключ во вкладке настроек веб-панели (или запишите в `config.json` на micro-SD).
5. Сохраните и перезагрузите устройство — GeminiPuter готов к работе!
