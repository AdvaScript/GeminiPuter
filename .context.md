  - **Cardputer ADV** (Advanced revision with upgraded power regulation, display timings, and full pinout compatibility).

  - **Framework**: PlatformIO / Arduino-ESP32 (`m5stack-stamps3`)
  - **OS / Concurrency**: FreeRTOS with dual-core task pinning & mutex synchronization
  - **GUI**: LVGL 8.x + SquareLine Studio generated base + custom Cyrillic font `rubik_14_cy`
  - **LED Engine**: FastLED 3.9+ running on a dedicated FreeRTOS task
  - **Networking / Server**: ESPAsyncWebServer + AsyncTCP + WiFiClientSecure
  - **JSON Processing**: ArduinoJson 6.21+
  - **AI Engine**: Google Gemini API (`v1beta/models/...:generateContent`) with Function Calling

## 🛠️ 2. Architectural Blueprint & File Map

### Core Source Files (`/PIO/src/`):
1. **`main.cpp`**:
   - Entry point: `setup()` and `loop()`.
   - FreeRTOS tasks:
     - `lv_tick_task` (Core 1, 4KB stack) - LVGL system tick every 10ms.
     - `lvgl_task` (Core 1, 8KB stack) - LVGL handler and UI redraws.
     - `ledTask` (Core 0, 4KB stack) - Dedicated WS2812 animation loop.
     - `wifiConnectTask` (Core 0, 8KB stack) - Background Wi-Fi connector and captive portal manager.
     - `chatWorkerTask` (Core 1, 16KB stack) - Detached asynchronous task executing Gemini HTTPS requests so the UI never blocks and watchdog timer (WDT) never triggers.
   - Synchronizations:
     - `lvglMutex`: Protects LVGL state calls (`lvglLock()` / `lvglUnlock()`).
     - `ledMutex`: Protects `currentLedState` and `customLedPattern`.
     - `transcriptMutex`: Protects `conversationTranscript` (capped at 6000 chars) against concurrent reads/writes from Web and Cardputer tasks.
   - Keyboard & UI:
     - `handleGeminiChatKeyboard()`: QWERTY input, arrow scrolling, tab focus toggling.
     - Russian layout mapper: `getMappedChar()`, phonetic transliteration, `rubik_14_cy` rendering.
     - HUD Toast: `initLangToast()`, `showLangToast(bool isRu)` showing semi-transparent `[ РУС ]` / `[ ENG ]`.
     - Styling: `ui_TextArea_AI_response` text color set to electric blue (`#38B6FF`); `ui_TextArea_chat_input` aligned to right (`LV_TEXT_ALIGN_RIGHT`).
   - Hardware Function Dispatcher:
     - Implemented in `geminiChat.setDeviceFunctionHandler(...)`.
     - Translates function calls from Gemini:
       - `set_screen_brightness`: Maps 1-100% to PWM duty cycle (5..255).
       - `set_led_effect`: Maps 11 effects and color hex codes to FastLED state.
       - `generate_led_pattern`: Executes step-by-step custom JSON animations.
       - `get_battery_percentage`: Queries real battery percentage from internal power sensor.

2. **`GeminiChat.h` / `GeminiChat.cpp`**:
   - Model management: Defaults to `gemini-3.1-flash-lite`, fallback to `gemini-2.5-flash`.
   - Payload construction:
     - `systemInstruction`: Tells Gemini it is running on Cardputer with 240x135 screen, requires concise 1-2 sentence answers, and instructs tool usage for hardware control.
     - `tools`: Declares function schemas for `set_screen_brightness`, `set_led_effect`, `generate_led_pattern`, and `get_battery_percentage`.
     - `contents`: Multi-turn message history (`kMaxHistoryTurns = 6`).
     - `generationConfig`: `maxOutputTokens = 250`, `thinkingConfig["thinkingBudget"] = 0` (zero latency mode to bypass reasoning delay).
   - Execution Loop:
     - Multi-turn function execution loop (up to 3 rounds).
     - Calls `_functionHandler(fnName, argsJson)` and sends `functionResponse` back to Gemini.
     - Watchdog safe: Yields and delays between calls.

3. **`WiFiManagerHandler.h` / `WiFiManagerHandler.cpp`**:
   - Serves the Cyberpunk Web HUD at `http://<ip>/` and `http://<ip>/chat`.
   - Endpoints:
     - `GET /api/transcript`: Returns current transcript JSON. Web JS parses `> User:`, `> Web:` into right-aligned user bubbles and `Gemini:` into blue left-aligned bubbles.
     - `GET /api/state`: Returns live hardware telemetry (battery %, screen brightness, LED effect, LED color hex, Wi-Fi RSSI, uptime, free heap, thinking state).
     - `POST /api/send_input`: Receives prompt string from desktop/phone browser.
     - `POST /api/shake`: Triggers Easter egg tilt test.
     - `POST /save`: Saves API key, Model name, Wi-Fi SSID and Password to NVS `Preferences`.
     - `POST /restart`: Safely reboots Cardputer.

4. **`lib/ui/`**:
   - SquareLine Studio generated base files: `ui.c`, `ui.h`, screens `ui_Screen_AiChat`, `ui_Screen_loading`, `ui_Screen_Menu`, `ui_Screen_status`.
   - Cyrillic font: `rubik_14_cy` embedded as C array.

## 🐛 3. Critical Bugs Solved & Lessons Learned

| Bug / Problem | Root Cause | Solution Implemented |
| :--- | :--- | :--- |
| **HTTP 404 on API requests** | Upstream code used `gemini-1.5-flash`, which is deprecated/removed in Gemini API. | Upgraded to `gemini-3.1-flash-lite` and allowed dynamic model selection via NVS. |
| **`task_wdt: Task watchdog got triggered`** | Gemini HTTPS call was running synchronously in the main loop, blocking FreeRTOS idle task and LVGL for >5-10 seconds. | Pinned chat worker to separate FreeRTOS task `chatWorkerTask` with 16KB stack on Core 1. |
| **LED crash during function call** | FastLED and M5.Led conflicting on GPIO G21; FastLED dithering causing watchdog timeouts. | Disabled dithering (`DISABLE_DITHER`), isolated LED rendering into `ledTask` with mutex protection, disabled `M5.Led`. |
| **Brightness stuck at 80%** | Function call arguments varied (`brightness`, `level`, `value`, `brightness_percent`) and fallback defaulted to 80. | Implemented multi-key argument parser checking all aliases and mapped `1..100%` linearly to `5..255` PWM. |
| **Missing Russian keyboard layout** | Cardputer firmware only handled standard US ASCII. | Created phonetic QWERTY-to-Cyrillic mapper toggled with `Fn + Backspace` / `Fn + Enter` and rendered via `rubik_14_cy`. |
| **Ugly missing glyph rectangles** | Flags/emojis in HUD toast could not be rendered by the 8-bit bitmap font. | Replaced with clean text `[ РУС ]` and `[ ENG ]`. |
| **Binary polluting Git repository** | `GeminiPuter.bin` was checked into Git tree. | Untracked via `git rm --cached`, added `*.bin` to `.gitignore`, and moved binary delivery to GitHub Releases `v2.0`. |
| **Model thinking latency** | Gemini 2.0/2.5/3.1 flash models spend tokens "thinking" before first text token. | Explicitly added `"thinkingConfig": {"thinkingBudget": 0}` in `generationConfig`. |

## 🎛️ 4. Hardware Function Calling Reference

When Gemini decides to execute hardware commands, it calls one of these 4 declared tools:

1. **`set_screen_brightness`**:
   - Parameters: `{"brightness_percent": integer (1..100)}`
   - Actions: Converts percentage to 5..255 PWM duty cycle via `M5Cardputer.Display.setBrightness()`.
2. **`set_led_effect`**:
   - Parameters: `{"effect": string, "color": string, "brightness_percent": integer}`
   - Supported effects: `solid`, `breathe`, `blink`, `rainbow`, `cyber_pulse`, `aurora`, `fire`, `starlight`, `police`, `alert`, `off`.
   - Colors: Named (`red`, `green`, `blue`, `yellow`, `cyan`, `magenta`, `purple`, `orange`, `white`) or hex `#RRGGBB`.
3. **`generate_led_pattern`**:
   - Parameters: `{"steps": [{"color": string, "duration_ms": integer}]}`
   - Actions: Parses step sequence into `customLedPattern` executed cyclically by `ledTask`.
4. **`get_battery_percentage`**:
   - Parameters: None
   - Actions: Reads ADC / AXP power sensor and returns percentage integer (`0..100%`).

## ⌨️ 5. Keyboard Shortcut Mappings

- **`Tab`**: Switch focus between Chat Input and AI Response transcript.
- **`Fn + ;`** / **`Fn + .`**: Scroll chat transcript Up / Down.
- **`Enter`**: Submit message.
- **`Fn + Backspace`** or **`Fn + Enter`**: Toggle Russian phonetic / English layout.
- **`Ctrl + L`**: Clear conversation transcript.
- **`/shake`** or **`/puke`**: Trigger Easter egg animation and shake test.

## 🚀 6. Build, Flashing & Release Commands

### Build from source:
```bash
cd PIO
~/.platformio/penv/bin/pio run
```
Output binary: `PIO/.pio/build/m5stack-stamps3/firmware.bin`

### Flashing via esptool:
```bash
esptool.py --chip esp32s3 write_flash 0x0 GeminiPuter.bin
```

### GitHub Release Creation (via `gh` CLI):
```bash
gh release create vX.X ./GeminiPuter.bin --title "Title" --notes "Release notes"
```

## 🔒 7. Security Guidelines
- **NEVER** hardcode Google Gemini API keys or Wi-Fi passwords in any source file.
- All credentials must be read dynamically from ESP32 NVS `Preferences` or `/config.json` on the SD card.
- `.gitignore` must always contain `*.bin`, `GeminiPuter.bin`, `.pio`, and `.vscode`.
